# Coin Collector

The finished game of the documentation's tutorial. Menu/two levels/player moved by an input action map/coins collected through trigger colliders/timer HUD/pause menu.

## Running it

Open the folder from the Project Hub (**Add Existing...**). The editor compiles the module on first open. Until it has, `Main.scene` reports its `MainMenu` row as an unloaded type (the normal first-open state of a project with code).
